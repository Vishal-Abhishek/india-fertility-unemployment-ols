# Female Unemployment and Fertility Dynamics in India: A Time-Series Econometric Analysis (1991–2023)
# Overview
Estimate the impact of female unemployment on fertility after controlling for structural demographic changes.
# Model Specification
Fertility = b0 + b1Female Unemployment + b2Urbanization + et
# Dataset
Source : World Bank
Period : 1991-2023
Frequency : Annual
# Variables
Dependent: Fertility Rate
Independent: Female Unemployment Rate
Control: Urbanization Rate
